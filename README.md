# 🐦 Portfólio — Desenvolvimento de Sistemas

Portfólio pessoal desenvolvido durante o curso Técnico em
Desenvolvimento de Sistemas.

> 📚 Este repositório é um projeto educacional desenvolvido por
> um aluno do ensino técnico. Seu objetivo é reunir projetos,
> experimentos e aprendizados desenvolvidos durante minha formação.

## 🎯 Sobre o projeto

Este site funciona como meu portfólio acadêmico e pessoal,
reunindo projetos desenvolvidos durante meus estudos em
Desenvolvimento de Sistemas.

O projeto também serve como laboratório para colocar em
prática conhecimentos de HTML, CSS, JavaScript, APIs,
Git/GitHub e desenvolvimento web.

## ✨ Funcionalidades

- 👤 Sistema de perfis
